Bob Runs

Method Endpoint Description
POST /api/bob/prompt Run a Bob Shell prompt synchronously and wait for the full result before returning.
POST /api/bob/jobs Start a Bob Shell prompt as a background async job; returns a job ID immediately for polling.
GET /api/bob/jobs List all Bob jobs currently held in server memory.
GET /api/bob/jobs/{job_id} Poll the status and streamed output of a specific background Bob job.
POST /api/bob/jobs/{job_id}/cancel Send SIGTERM to a running Bob job and mark it cancelled.
DELETE /api/bob/jobs/{job_id} Delete a completed job record and clean up its on-disk workspace artifacts.
GET /api/bob/jobs/{job_id}/artifacts/{artifact_name} Download a named artifact file (e.g. result.md, bob-run.json) from a Bob job run.
POST /api/bob/stream Run a Bob Shell prompt and stream incremental output back as Server-Sent Events (SSE).

Workflows — Plan → Approve → Execute

Method Endpoint Description
POST /api/workflows Create a new skill-aware workflow from a plain-text objective; returns a plan for review or auto-executes if autoApprove=true.
GET /api/workflows List all in-memory workflows with their current state.
GET /api/workflows/{workflow_id} Get the full plan, skill selection, execution status, activity log, and results for a workflow.
POST /api/workflows/{workflow_id}/approve Approve a workflow that is paused waiting for human sign-off; execution resumes immediately.
POST /api/workflows/{workflow_id}/cancel Cancel a running or pending workflow and kill any active child process group.
DELETE /api/workflows/{workflow_id} Remove a terminal (completed or cancelled) workflow from server memory.
GET /api/workflows/{workflow_id}/artifacts/{artifact_name} Download a named artifact produced by a workflow execution run.

Bob+ Planning Sessions NEW

Method Endpoint Description
POST /api/sessions Create a new 5-phase Bob+ planning session (Describe → Discovery → Architecture → Spec → Continue).
GET /api/sessions/current Return the currently active session including all phase states and conversation history.
POST /api/sessions/{session_id}/message Send a user message in the active phase; returns Bob's response, any phase-transition signal, and artifact update flag.
POST /api/sessions/{session_id}/advance Advance the session to the next phase after the user confirms a Bob-proposed transition.
GET /api/sessions/{session_id}/artifact/{phase_id} Retrieve the generated markdown artifact for a completed phase (e.g. requirements.md, spec.md).
DELETE /api/sessions/{session_id} Destroy the active session and clear all conversation state from memory.

Infrastructure

Method Endpoint Description
GET /healthz Liveness probe — returns {"status":"ok"}. Used by Kubernetes / load-balancer health checks.
POST /mcp MCP JSON-RPC 2.0 endpoint — exposes Bob Shell and workflow tools to any MCP-compatible client or AI assistant.

Authentication

Method Details
Basic Auth Send Authorization: Basic <base64(username:password)>. Default credentials: admin / nowibm (set via BOBSERVER_ADMIN_USERNAME / BOBSERVER_ADMIN_PASSWORD).
OAuth2 Bearer Obtain a token via POST /oauth/token (PKCE flow) and send Authorization: Bearer <token>. Token TTL: 3600 s.
IBM App ID Browser-based SSO via GET /auth/login. Requires BOBSERVER_APPID_* environment variables to be configured.
