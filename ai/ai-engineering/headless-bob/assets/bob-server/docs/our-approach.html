Bob Server: Our Approach

Start with the real Bob CLI in a governed container, expose it through UI and MCP, then evolve toward isolated jobs and a native Bob-compatible agent service as the platform scales.

Phase 1: Prove Value

Wrap the real Bob CLI in a containerized service. This gives us the highest fidelity to Bob today and makes UI plus MCP demos real.

Phase 2: Govern Execution

Move long-running work into tenant, user, and job-scoped execution with policy, logs, artifacts, cancellation, and audit.

Phase 3: Scale Platform

Introduce a native Bob-compatible agent service for better streaming, session control, tool policy, and horizontal scale.
