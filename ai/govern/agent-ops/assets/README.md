# Agent Ops — Assets

Technical assets for evaluating AI agents. Choose the folder that matches your agent framework:

| Folder | Agent framework | What it provides |
|---|---|---|
| [wxo-agents/](wxo-agents/) | **watsonx Orchestrate** agents | ADK evaluation framework scripts (quick-eval, test-case generation, evaluate, analyze, red-teaming), a single-agent sample, and the validated multi-agent **loan-underwriting** example with ground-truth cases, a rubric, and red-team attacks |
| [langgraph-agents/](langgraph-agents/) | **LangGraph / LangChain** agents | Python SDK package for evaluating RAG quality, tool-calling accuracy, and content safety of LangGraph agents with watsonx.governance |

Cost and token spend in dollars (Langfuse) lives in the [Cost Management](../../cost-management/) building block.
