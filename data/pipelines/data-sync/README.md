# Data Sync

**IBM product**: IBM Aspera Sync

Use for high-speed synchronization of large file and directory repositories across sites, networks, and cloud locations.

This is not relational CDC. For structured database replication, use IBM watsonx.data integration Data Replication.

Actual transfer throughput depends on network capacity, endpoint/storage performance, configuration, and workload characteristics.
