# Context Hub

**IBM products**: IBM Confluent, IBM watsonx.data, IBM watsonx.data intelligence

Context Hub is an **architectural pattern**, not a standalone IBM product. It combines data in motion, data at rest, and governed metadata so applications and AI systems can consume fresher, trusted context.
