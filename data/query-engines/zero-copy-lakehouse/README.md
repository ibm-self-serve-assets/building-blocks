# Zero-Copy Lakehouse

**IBM product**: IBM watsonx.data

Reference assets for querying governed data across supported sources using IBM watsonx.data query engines and open table formats without unnecessary data duplication.

## Included assets

| Path | Purpose |
|---|---|
| [`assets/setup-lakehouse/`](assets/setup-lakehouse/) | Lakehouse setup/reference automation |
| [`bob-modes/`](bob-modes/) | IBM Bob lakehouse mode |
| [`bob-skills/watsonxdata-lakehouse.zip`](bob-skills/watsonxdata-lakehouse.zip) | IBM Bob watsonx.data lakehouse skill |
| [`bob-skills/iceberg-table-management.zip`](bob-skills/iceberg-table-management.zip) | IBM Bob Iceberg table-management skill |

“Zero-copy” refers to querying supported data in place where the selected connector/engine permits it; it is not a guarantee that every operation avoids all data movement.
