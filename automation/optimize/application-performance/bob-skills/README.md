# Application Performance Skills

Application Performance building blocks enable continuous AI-powered resource management, cloud workload sizing, and performance assurance using IBM Turbonomic.

## 📦 Available Assets & Skills

### `automated-resource-mgmt-turbonomic.zip`

A comprehensive skill and automation package for IBM Turbonomic integration, providing capabilities for:

- **Turbonomic Dashboards**: Building interactive Dashboards with IBM Carbon themes for monitoring infrastructure entities, pending actions, and target health.
- **Turbonomic v3 API Integration**: Developing robust API clients for fetching topology entities, executing actions, and querying performance metrics.
- **Automated Resource Optimization**: Managing batch action execution, policy automation, and resource sizing for VMs, containers, and Kubernetes.

## 🚀 Installation and Setup

### Step 1: Extract the Skill to Bob Workspace
Extract the `automated-resource-mgmt-turbonomic.zip` archive into your Bob workspace skills directory:

```bash
# Navigate to your Bob workspace skills directory
cd /path/to/your/bob/workspace/.bob/skills

# Extract the package
unzip /path/to/automation/optimize/application-performance/bob-skills/automated-resource-mgmt-turbonomic.zip
```

### Step 2: Verify Installation
Check that the skill files are present:

```bash
ls -la .bob/skills/
```

### Step 3: Activate in Bob
1. Open Bob and select your preferred mode.
2. Ensure the **Skills** option is enabled.
3. The Application Performance capabilities will be active and ready to assist.
