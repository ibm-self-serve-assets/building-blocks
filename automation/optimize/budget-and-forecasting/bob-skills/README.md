# Budget & Forecasting Skills

Budget & Forecasting building blocks enable natural-language financial analysis, multi-dimensional OLAP queries, and variance modeling using IBM Planning Analytics (TM1).

## 📦 Available Assets & Skills

### `planning-analytics-skill.zip`

A comprehensive skill and automation package for IBM Planning Analytics, providing capabilities for:

- **Natural Language Financial Queries**: Translating plain-English business questions directly into MDX queries against Planning Analytics cubes.
- **Financial Variance Analysis**: Comparing budget vs actual, period-over-period, and forecast accuracy metrics.
- **Outlier Detection & Key Drivers**: Identifying unusual expense spikes and ranking key variance drivers.
- **Executive Reporting**: Generating automated variance reports with AI explanations and insights.

## 🚀 Installation and Setup

### Step 1: Extract the Skill to Bob Workspace
Extract the `planning-analytics-skill.zip` archive into your Bob workspace skills directory:

```bash
# Navigate to your Bob workspace skills directory
cd /path/to/your/bob/workspace/.bob/skills

# Extract the package
unzip /path/to/automation/optimize/budget-and-forecasting/bob-skills/planning-analytics-skill.zip
```

### Step 2: Verify Installation
Check that the skill files are present:

```bash
ls -la .bob/skills/
```

### Step 3: Activate in Bob
1. Open Bob and select your preferred mode.
2. Ensure the **Skills** option is enabled.
3. The Budget & Forecasting capabilities will be active and ready to assist.
