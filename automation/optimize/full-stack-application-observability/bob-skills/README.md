# Application Observability Skills

Full-Stack Application Observability building blocks enable distributed tracing, incident intelligence, and service health monitoring with IBM Instana and OpenTelemetry.

## 📦 Available Assets & Skills

### `application-observability.zip`

A comprehensive skill and automation package for IBM Instana integration, providing capabilities for:

- **Instana Observability Dashboards**: Building interactive Dashboards with service health visualizations and composite health scores.
- **REST API Integration**: Developing robust API clients for fetching application metrics, traces, and incident lifecycles.
- **Incident & Event Intelligence**: Automated root cause analysis, Kubernetes event correlation, and problem detection.
- **MCP Server Deployment**: Configuring and deploying the Instana Model Context Protocol (MCP) server for AI-assisted operations.

## 🚀 Installation and Setup

### Step 1: Extract the Skill to Bob Workspace
Extract the `application-observability.zip` archive into your Bob workspace skills directory:

```bash
# Navigate to your Bob workspace skills directory
cd /path/to/your/bob/workspace/.bob/skills

# Extract the package
unzip /path/to/automation/optimize/full-stack-application-observability/bob-skills/application-observability.zip
```

### Step 2: Verify Installation
Check that the skill files are present:

```bash
ls -la .bob/skills/
```

### Step 3: Activate in Bob
1. Open Bob and select your preferred mode.
2. Ensure the **Skills** option is enabled.
3. The Full-Stack Application Observability capabilities will be active and ready to assist.
