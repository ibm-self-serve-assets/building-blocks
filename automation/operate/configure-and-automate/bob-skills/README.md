# Configure & Automate

Configure & Automate building blocks enable automated configuration management, playbook orchestration, and repeatable infrastructure workflows using tools like Ansible.

## 📦 Available Assets & Skills

### `configure-and-automate.zip`

A comprehensive skill and automation package for configuration management and automation, providing capabilities for:

- **Playbook & Role Development**: Developing and maintaining declarative automation playbooks, reusable roles, and dynamic inventories.
- **Script Modernization**: Converting imperative shell/bash scripts and manual setup procedures into idempotent, declarative playbooks.
- **Debugging & Troubleshooting**: Systematic resolution of connectivity, execution, variable precedence, and syntax issues.
- **Idempotency & Best Practices**: Ensuring idempotent automation execution with fully qualified collection names (FQCN) and safe check-mode validations.

## 🚀 Installation and Setup

### Step 1: Extract the Skill to Bob Workspace
Extract the `configure-and-automate.zip` archive into your Bob workspace skills directory:

```bash
# Navigate to your Bob workspace skills directory
cd /path/to/your/bob/workspace/.bob/skills

# Extract the package
unzip /path/to/automation/operate/configure-and-automate/configure-and-automate.zip
```

### Step 2: Verify Installation
Check that the skill files are present:

```bash
ls -la .bob/skills/
```

### Step 3: Activate in Bob
1. Open Bob and select your preferred mode.
2. Ensure the **Skills** option is enabled.
3. The configuration and automation capabilities will be active and ready to assist.
