# Automation Building Blocks

The **Automation Building Blocks** represent a curated portfolio of IBM capabilities and automated engineering patterns designed to streamline enterprise IT operations, security posture, application performance, and cloud economics.

---

## 🏗️ 1. Operate

Operate building blocks provide blueprints and skills for automated infrastructure provisioning, configuration orchestration, workload management, and enterprise asset workflows.

| Subfolder | Description | Primary Technologies & Capabilities |
| :--- | :--- | :--- |
| **[infrastructure-as-code](operate/infrastructure-as-code/)** | Declarative infrastructure provisioning, multi-cloud blueprints, load-testing, and automated deployment pipelines. | Terraform, OpenTofu, JMeter, AWS/Azure/GCP |
| **[configure-and-automate](operate/configure-and-automate/)** | Automation playbooks, configuration management, and imperative-to-declarative script transformation. | Ansible, Python, Shell |
| **[workload-orchestration-and-scheduling](operate/workload-orchestration-and-scheduling/)** | Enterprise workflow scheduling and distributed workload orchestration. | Workload Automation, Schedulers |
| **[asset-management](operate/asset-management/)** | Asset lifecycle management, intelligent enterprise asset modernization, and knowledge assistants. | Maximo Application Suite, AI Assistants |

## 🛡️ 2. Secure

Secure building blocks focus on identity protection, continuous compliance, vulnerability mitigation, and post-quantum cryptographic readiness.

| Subfolder | Description | Primary Technologies & Capabilities |
| :--- | :--- | :--- |
| **[non-human-identity-and-secret-management](secure/non-human-identity-and-secret-management/)** | Secrets governance, NHI lifecycle management, and secrets migration workflows. | IBM Security Verify, HashiCorp Vault |
| **[application-risk-and-continuous-compliance](secure/application-risk-and-continuous-compliance/)** | Continuous resilience, posture management, CVE discovery, and automated compliance tracking. | IBM Concert, DevSecOps |
| **[cryptographic-and-quantum-safe-readiness](secure/cryptographic-and-quantum-safe-readiness/)** | Quantum-vulnerable algorithm discovery, crypto inventory (CBOM), and remediation workflows. | IBM Quantum Safe Explorer, Guardium Cryptographic Manager |

## ⚡ 3. Optimize

Optimize building blocks deliver full-stack observability, automated resource sizing, financial management, and network analytics.

| Subfolder | Description | Primary Technologies & Capabilities |
| :--- | :--- | :--- |
| **[full-stack-application-observability](optimize/full-stack-application-observability/)** | End-to-end telemetry, automated dependency discovery, and distributed application monitoring. | IBM Instana, OpenTelemetry |
| **[application-performance](optimize/application-performance/)** | AI-driven resource sizing, performance assurance, and automated remediation. | IBM Turbonomic |
| **[technology-financial-management-and-finops](optimize/technology-financial-management-and-finops/)** | Cloud unit economics, IT financial planning, cost allocation, and optimization insights. | IBM Apptio, Cloudability |
| **[network-performance-management](optimize/network-performance-management/)** | Network observability, performance analytics, and latency/bandwidth diagnostics. | Network Monitoring, Diagnostics |
| **[budget-and-forecasting](optimize/budget-and-forecasting/)** | AI-assisted financial modeling, FP&A variance analysis, and predictive enterprise budgeting. | IBM Planning Analytics, TM1 |
