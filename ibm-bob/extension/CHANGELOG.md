# What's New in Bob+ Extension

## Version 1.1.0
*Latest Release*

- **Renamed to Bob+: Assets** — the extension title and activity bar panel now read "Bob+: Assets" for consistency.
- **Modes removed** — the Modes section has been removed from the panel. The extension now focuses exclusively on Building Blocks and Specs.
- **Skills renamed to Building Blocks** — the Skills section is now called "Building Blocks" throughout the UI, including section headers, badges, search placeholder, and summary bar.
- **Demos renamed to Specs** — the Demos section is now called "Specs".
- **Live refresh from GitHub** — hitting the ↺ Refresh button now bypasses all in-memory caches and fetches the latest data directly from GitHub. Domain grouping changes take effect immediately on refresh.
- **Parser bug fix** — fixed some minor bugs in parsing.
- **Demo gallery** — browse screenshots, videos, architecture diagrams, and source links for AI demos directly from the sidebar.
- **Auto MCP configuration** — Building Blocks that require MCP servers are now configured automatically on install.
- **Improved caching** — Building Blocks and Specs are cached locally, reducing load times on repeat visits.

## Version 1.0.0
*Initial Release*

- Browse and install AI skills for Bob directly from the sidebar. Each skill adds new capabilities to your assistant with a single click.
- Switch Bob's persona and behavior by installing pre-built modes — from domain expert agents to specialized assistants.
- Quickly find the skill or mode you need with built-in search across all marketplace content.
